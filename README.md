Ebus Management Based Current Location System
Live Demo: https://clinquant-bienenstitch-f45632.netlify.app/

📌 Overview
Ebus Management Based Current Location System is a web-based application designed to enhance the public transportation experience by providing real-time tracking of buses. This system allows users to view current bus locations on a map, improving travel planning, reducing wait times, and enhancing overall transparency in transit management.

🚀 Features
🗺️ Live Bus Tracking: Displays real-time location of buses on an interactive map.

📍 User Location Detection: Automatically detects the user’s current location for convenience.

🚌 Bus Info Overlay: Shows key details such as bus number, route, and estimated time of arrival (ETA).

🌐 Responsive Design: Accessible from both desktop and mobile devices.

💡 Technologies Used
Frontend: HTML, CSS, JavaScript

Deployment: Netlify

🛠️ How It Works
The system uses GPS coordinates to pinpoint the current locations of buses.

These locations are then displayed in real time using a map service.

Users can identify nearby buses, view their paths, and determine the best options for travel.
